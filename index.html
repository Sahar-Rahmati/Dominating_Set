Educational Content

Overview

Dominating Set asks whether there exists D with |D|<=k such that every vertex is in D or adjacent to a vertex in D.

Worked Example

On path 0-1-2-3-4, choosing D={1,3} dominates all vertices.

Key Concepts
  • Exact brute-force is exponential because it may test up to 2^n subsets.
  • The practical algorithm is a greedy heuristic: repeatedly choose the vertex that dominates the largest number of still-undominated vertices.
  • This is the standard Set Cover greedy idea applied to closed neighborhoods N[v]. It gives an O(log n)-type approximation guarantee, but it is not always optimal.
Greedy Counterexample

Greedy can pick a high-coverage vertex early and later need extra vertices, while an exact solution uses fewer carefully placed vertices. Use Comparison mode to show this: brute force proves the optimum, while greedy explains the locally best choices.

      NP-Completeness Section

      In NP

      • Certificate: subset D with |D|<=k.
      • Verifier checks every vertex is either in D or adjacent to a vertex in D.
      • Using adjacency lists, verification takes O(n+m), so the problem is in NP.

      Reduction from Vertex Cover

      • Start with a Vertex Cover instance (G,k). First remove isolated vertices; they affect neither vertex cover nor the reduction.
      • Build G' by keeping all original vertices and original edges of G.
      • For every edge e=(u,v), add one gadget vertex w_e adjacent exactly to u and v.
      • Use the same bound k. The construction has |V|+|E| vertices and at most 3|E| edges, so it is polynomial.

      Correctness (Forward + Backward)

      • Forward: If C is a vertex cover of G with |C|<=k, then every non-isolated original vertex is dominated by itself or by a selected neighbor, and every gadget w_e is dominated by the selected endpoint covering e. Thus C is a dominating set of G'.
      • Backward: If D is a dominating set of G' with |D|<=k, replace any selected gadget w_e by one endpoint of e. Because the original edge is kept, this does not increase the size or destroy domination.
      • After replacement, D contains only original vertices. Each gadget w_e is adjacent only to the endpoints of e, so one endpoint of every original edge must be selected. Therefore D is a vertex cover of G.
      • So (G,k) is a yes-instance of Vertex Cover iff (G',k) is a yes-instance of Dominating Set. Since Vertex Cover is NP-complete and Dominating Set is in NP, Dominating Set is NP-complete.
