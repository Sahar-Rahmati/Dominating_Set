Educational Content

Overview

Dominating Set asks whether there exists D with |D|<=k such that every vertex is in D or adjacent to a vertex in D.

Worked Example

On path 0-1-2-3-4, choosing D={1,3} dominates all vertices.

Key Concepts
  • Exact brute-force is exponential.
  • Greedy picks the vertex with maximum new coverage.
  • Greedy is linked to Set Cover with O(ln n) approximation analysis.

      NP-Completeness Section

      In NP

      • Certificate: subset D, |D|<=k.
      • Verifier checks each vertex is in D or has neighbor in D.
      • Polynomial verification: O(n+m) with adjacency list.

      Reduction from Vertex Cover

      • Given VC instance (G,k), create G'.
      • For each edge (u,v), add gadget vertex w_uv connected only to u and v.
      • Claim: VC yes-instance iff DS yes-instance with same k.
      • Construction is polynomial in |V|+|E|.

      Correctness (Forward + Backward)

      • Forward: VC set C dominates all original vertices and each gadget w_uv through u or v in C.
      • Backward: Any gadget in D can be replaced by endpoint without increasing size; then every edge must have at least one endpoint in resulting set, so it is a vertex cover.
      • Hence Dominating Set is NP-complete.
